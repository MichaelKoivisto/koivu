# Koivu Project Contributing Guidelines

We welcome contributions. Please adhere to the following rules when submitting work:

* While we embrace tools that improve efficiency, we must avoid committing code we do not understand. 
* Documentation updates should maintain an analytical, active voice and a "hacker-classic" tone. Please avoid marketing jargon or hyperbole.
* Don't be _not a good person_.
